## 1. 成员端（成员视角）

### 1.1 登录

打开 `http://clab.foliagepeer.cn/`，输入学号 + 密码。

- 密码错了会提示「学号或密码错误」，**不会区分**是你学号打错还是密码打错（这是有意的，防止别人试探学号是否存在）
- 页面底部写着「初始密码为学号后六位，登录后可在报告最后一页修改」
- 连续输错 5 次会锁 10 分钟（同一个人），提示「错误次数过多，请 X 分钟后再试」
- **已经登录过的话**，再次打开会直接进报告页，不用重新登录（登录状态保留 7 天）

### 1.2 报告页怎么翻

进报告后默认是 **8 屏**（「页面」页签可增删、排序、停用，实际页数以面板为准），**手指上下滑**翻页（电脑上可以用滚轮/拖拽）：

1. 封面 —— 姓名 + 部门 + 年度 + 个人照片（照片作为整页背景）
2. 志愿时长 —— 大数字从 0 滚到累计时长（小数保留 1 位）
3. 活动足迹 —— 参与次数 + 部分活动名称
4. 活动回忆① —— 活动名称、日期、现场照片（背景）与本人承担的工作
5. 活动回忆② —— 另一次活动的照片与工作内容
6. 同行伙伴 —— 伙伴人数 + 集体合照（背景）
7. 年度关键词 —— 关键词 + 一句依据
8. 部长寄语 —— 寄语 + 部门合照/背景；「修改密码」「退出登录」在最后一页

每屏的文字有淡入/上浮动画，**每次滑回该屏动画会重播**；右侧小圆点是页码，可以直接点着跳。

### 1.3 背景音乐开关

**如果管理员给这位成员配了音乐**，报告页**右上角**会出现一个圆形按钮：

- 有呼吸动画 = 正在播放
- 上面有一道斜杠 = 暂停（**手机浏览器常会拦截自动播放**，点一下就开始，这是浏览器的限制不是故障）
- 自己关掉之后，下次登录不会再自动响（选择记在这台手机上）
- 退出登录会停止播放

### 1.4 修改密码

结尾页 →「修改密码」→ 填当前密码 + 新密码（6–64 位，不能和当前密码相同）+ 再输一次。

改完之后**其他设备上的登录会立刻失效**（当前这台不受影响）。忘记密码的话只能找管理员重置。

### 1.5 成员常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 听不到声音 | 先看右上角按钮：有斜杠就点一下；再看看手机媒体音量；还是没有就说明只配了静音测试音或没配音乐 |
| 背景是纯色/渐变，没有照片 | 该成员（或所有人）还没配背景图，页面用自带的深色渐变兜底；管理员可在媒体页上传 |
| 登录不上，提示网络连接失败 | 换 WiFi／换浏览器再试；现在版本遇到这类网络中断会自动重试一次 |
| 想看别人的报告 | 不行，一个账号只能看到自己的 |

### 1.6 字体、配色与边缘动效

管理员可以给报告配「外观主题」，不同成员可能看到不同风格：

- **配色**：装饰颜色（音符/光点）、大数字的渐变色、背景图的压暗颜色与程度都可能被主题改过
- **字体**：标题/大数字与正文可能换成了别的字体；字体没加载完时会先用系统字体显示，不会卡住报告
- **边缘动效**：屏幕两侧会缓慢上浮小音符与细碎光点
- **环境光效**：屏幕两侧有细碎光点上浮，切到新一屏时画面中心会扩散一次光圈
- 手机开了「减少动态效果」（无障碍设置）时，以上装饰与光效会自动隐藏
- 登录页与修改密码页**不套主题**，保持统一样式

## 2. 管理端（管理员用的）

### 2.1 登录与退出

`http://clab.foliagepeer.cn/admin` → 输入管理员用户名密码。

- 登录状态保留 **12 小时**（比成员的 7 天短）
- 右上角「退出」**只退管理面板**；登录管理面板也不会让同一浏览器里的成员登录掉线（两边是独立会话）
- 连续输错 5 次会锁 15 分钟
- 顶部如果有黄色横幅提示「容器对静态资源目录没有写权限」或「前后端版本不一致」，说明部署有问题，找负责人

### 2.2 五个页签

| 页签 | 做什么 |
|---|---|
| **成员** | 找人、改人、加人删人、勾选后批量操作、导出所选 |
| **媒体资源** | 给成员配背景图与背景音乐、批量上传文件 |
| **导入导出** | 粘贴文本批量添加、Excel 导入、导出名单、下载模板 |
| **外观** | 主题配色、字体、动效、页面排版 |
| **页面** | 页面注册表：增删页面、调整顺序、启用/停用、设置年度、编辑登录页前言 |

### 2.3 成员页：找人、看状态

- **搜索**：输入学号或姓名的一部分即可（实时过滤）
- 每行显示：`姓名（学号）` + 部门、入会日期（括号里是实时算出的天数）、志愿时长、活动次数
- 关键信息用蓝色小标签标出：`专属图目录：xxx`、`音乐：xxx`、`主题：xxx`（表示这个成员被单独指定过）
- 行内五个按钮：**编辑** / **媒体**（跳到媒体页并选中他）/ **主题**（单独设置主题）/ **预览**（看他会看到什么）/ **删除**
- 「主题」可以只给这一位成员换主题，不需要先勾选；选「默认主题」会清掉他的单独设置
- 「预览」很有用：它会列出该成员**实际会加载的** 8 张背景图（含从哪个位置找到的）和音乐，排查「图传了没生效」时先看这里

### 2.4 新增 / 编辑 / 删除单个成员

**新增**：工具栏「新增成员」→ 填学号、姓名（必填），其他可留空 → 保存。

- 密码留空 = 用**学号后六位**作初始密码（提示会告诉你）
- 用这个初始密码去成员端登录一次，能验证链路通了

**编辑**：行内「编辑」→ 改哪些填哪些（**只有你改过的字段会被提交**，没动的不会被覆盖）。

- 学号是灰色的（不可改）：它是主键，改学号等于删旧建新
- 「新密码」留空 = 不改密码；填了 = 重设，并让该成员在其他设备上下线
- 「背景图目录」留空 = 用学号当目录；「背景音乐」留空 = 找与学号同名的音频

**删除**：行内「删除」→ 红色确认框（会告诉你后果）→ 删除。**删错了可以在随后的提示上点「撤销」**（10 秒内），连原密码一起还原。

### 2.5 勾选后的批量操作

每行前面有勾选框，工具栏有「全选」。**选择会跨搜索保留** —— 可以先搜「2021」勾一批，再搜「2022」接着勾，最后一起处理。勾选后出现蓝色操作条：

| 按钮 | 作用 |
|---|---|
| **批量修改** | 把某个字段统一改成新值（见 2.6） |
| **批量媒体** | 批量配图/配音乐（见 2.7） |
| **导出所选** | 只把这几位导出成 Excel（文件名带人数） |
| **重置密码** | 全部重置为「学号后六位」，并强制他们其他设备下线 |
| **批量删除** | 删除并清理登录状态 |
| **取消选择** | 清空勾选 |

### 2.6 批量修改某字段

「批量修改」→ 选字段（部门 / 入会日期 / 志愿时长 / 活动次数 / 伙伴人数 / 年度关键词 / 关键词依据 / 部长寄语 / 背景图目录 / 背景音乐）→ 填新值 → 应用。选「入会日期」时，输入框会给出示例格式（`2024-09-01`）；其实 `20240901`、`2024/9/1`、`2024年9月1日` 这些写法也都认。

- **留空表示清空该字段**（清空背景图目录/音乐 = 回到「用学号」的默认规则）
- 数字字段要填数字，否则会提示
- 姓名和学号**不能**批量改（学号是主键，姓名批量改几乎必然是误操作），密码也不能批量设同一个值，只能走「重置密码」
- 改错了：10 秒内在提示上点「撤销」，字段回到改前的值

### 2.7 批量媒体操作

「批量媒体」→ 四选一：

| 操作 | 说明 |
|---|---|
| **指派背景音乐** | 从音乐库选一首；选第一项「（清空，回到与学号同名）」= 取消指定 |
| **设置背景图目录** | 填目录名（如 `shared-theme`）；**留空 = 回到各自的学号目录** |
| **上传专属背景图** | 选槽位 + 选图 → **同一张图写进每人各自的目录**（同名覆盖） |
| **删除专属背景图** | 选槽位 → 删掉这些人该槽位的专属图，他们回落到共享图；没有的会自动跳过 |

上传和删除是逐个成员执行并显示进度的。

### 2.8 导入导出

这一页有两种批量导入方式，**规则完全一致**（同样的列、同样的校验、同样的密码规则）：
**每学年的正式维护用 Excel**，临时补几个人用粘贴文本。

#### A. Excel 导入（每学年维护的主路径）

面板「导入导出」页 → **Excel 导入** 区：`选择 Excel 文件` → `预览` → `确认导入`；模板点 `下载导入模板` 拿。

1. **先下模板**：第一行是表头，下面两行是示例数据（正式用时删掉示例行）
2. **按列填写**（列名必须一致，建议顺序也照抄）：

   | 列 | 必填 | 说明 |
   |---|---|---|
   | 学号 | ✅ | 唯一标识；重复导入按学号更新，不会重复建人 |
   | 密码 | | 见下方「密码列的三种规则」 |
   | 姓名 | ✅ | |
   | 部门 | | |
   | 入会日期 | | 认 `2024-09-01`、`2024/9/1`、`2024.9.1`、`2024年9月1日`、`20240901`；报告里的天数由它自动算 |
   | 志愿时长 | | 数字，可带小数 |
   | 活动次数 | | 整数 |
   | 活动记录 | | 活动名称列表，用「、」分隔；用于活动足迹页 |
   | 活动一名称 / 日期 / 工作 | | 活动回忆①；日期写法同入会日期，可填多个用「、」分隔 |
   | 活动二名称 / 日期 / 工作 | | 活动回忆②；日期可填多个，用「、」分隔（如多次举办的评选） |
   | 伙伴人数 | | 整数；留空 = 按同部门成员数统计 |
   | 年度关键词 | | 如「现场定心丸」 |
   | 关键词依据 | | 一句话说明 |
   | 部长寄语 | | 单元格里的换行会保留 |
   | 背景图目录 | | 留空 = 用学号目录 |
   | 背景音乐 | | 留空 = 找与学号同名的音频 |

3. **选文件 → 预览**：逐行标出 `新增 / 更新 / 无变化 / 错误`，并说明改动了哪些字段、密码怎么处理；有问题的行会指到**具体第几行**（Excel 的真实行号），例如「第 6 行：这个日期不存在：2024-02-30」
4. **确认导入**：写入数据库。**换了文件或内容变过就必须重新预览**（系统会自动禁用确认按钮）
5. 工作表：默认读**第一个**工作表；如果你给它命名为 `students`，则优先读它
6. 上限：一次最多 5000 行

⚠️ **三个要知道的点**：
- **旧模板仍然能导入**：旧版 11 列（含「年度伙伴」）缺少的新列会**保留库里原值**，不会被清空；想清空新字段，请用新版模板并留空对应单元格
- 「背景图目录」「背景音乐」这两列**以 Excel 为准**：重新导入时留空 = **清掉**之前的设定（回到默认规则）。只想更新其他字段时，别把这两列留空，或者改用面板里的单条编辑
- 导出的 Excel 里密码列必然是空的 —— 直接改完再导回来就行：老成员保留原密码，新成员用学号后六位

#### B. 粘贴文本批量添加 / 更新（临时补人更快）

每行一名成员，字段顺序与 Excel 列一致（20 列）：

```

2099001,init123456,王小明,外联部,2024-09-01,60,8,迎新晚会、支教,迎新晚会,2026-09-10,现场统筹,支教,2026-07-15,课程设计,12,现场定心丸,总能稳住场面,继续加油,,
2099002,,张小美,宣传部,2025-03-15,40,5,海报设计,海报设计,2026-05-20,视觉设计,,,,8,创意补给站,总能给出新鲜方案,未来可期,,
```

- **旧版 11 列文本也识别**：没有的新列会保留库里的值；新模板里留空才会清空
- 「入会日期」认 `2024-09-01`、`2024/9/1`、`2024年9月1日` 等多种写法；旧模板里的「加入天数」列也兼容（按导入当天往前折算成日期）
- 「活动一日期」「活动二日期」都可以填多个日期，用「、」分隔（如 `2025-10-16、2025-11-28`），报告里会原样展示
- 逗号或 Tab 分隔（全角逗号也行），**字段里有逗号就用双引号包起来**
- 空行、`#` 开头的行会忽略；一行就是单条，多行就是多条
- 粘贴后先点「预览」：逐行标出 **新增 / 更新 / 无变化 / 错误**，并说明改动了哪些字段、密码怎么处理
- 确认无误再点「确认导入」（**改动过内容就必须重新预览**，防止预览与提交的不是同一份）

#### 密码列的三种规则（两种导入方式通用）

| 密码列 | 结果 |
|---|---|
| 填了值 | 用该值（可用于重置某人密码） |
| 留空 + 成员已存在 | **保留原密码不变**（只改其他字段时用这个） |
| 留空 + 新成员 | 用**学号后六位**作初始密码，导入结束会告诉你有多少人用了初始密码 |

#### C. 导出

「下载全部成员 Excel」导出所有人；只要部分人就在成员页勾选后点「导出所选」。

- 导出文件的**密码列必然是空的**（库里只有哈希，导不出明文）
- 改完这份 Excel 再导回来即可：老成员保留原密码，新成员用学号后六位
- 一次最多处理 5000 行 / 500 人

### 2.9 媒体资源页：配背景图与音乐

顶部下拉选成员，下面四块：

**① 该成员的专属背景图**（默认 8 个槽位，页面注册表可增删）

每个槽位显示当前生效的文件；「上传」选图（同名可替换）、「删除」去掉（回落到共享图）。同一槽位如果放了多种格式，会提示哪些「未生效」（格式优先级：jpg → jpeg → png → webp）。

**② 共享背景图**（同样 8 个槽位）

放这里的图**所有成员**都会用。专属图同槽位会覆盖共享图。

槽位名与页面的对应（个人照片/活动照片/合照都作为对应页的**整页背景**，文字叠在上面）：

| 槽位名 | 对应页 |
|---|---|
| `01-cover` | 封面（姓名/部门/年度 + 个人照片） |
| `02-hours` | 志愿时长 |
| `03-activities` | 活动足迹 |
| `04-memory-1` | 活动回忆①（现场照片） |
| `05-memory-2` | 活动回忆②（现场照片） |
| `06-partners` | 同行伙伴（集体合照） |
| `07-keyword` | 年度关键词 |
| `08-message` | 部长寄语（部门合照/背景） |

**③ 背景音乐**

「选择音频文件」+「上传音乐」→ 会问你存成什么文件名（默认建议 `<学号>.<后缀>`，**用学号命名就会自动归属该成员**）。列表里每条都能**试听**、看「被谁使用」、**设为当前选中成员的音乐**、删除。

- 支持 mp3 / m4a / ogg / wav；多个格式同名时按这个顺序取第一个
- 图片单张上限 5MB，音乐 10MB
- 文件一放上去就生效，**不需要重启任何东西**；换图后成员那边会自动看到新图（URL 带版本号，绕开浏览器缓存）

**④ 该成员的附加图片**

给某位成员额外加照片，照片显示在**对应页面内**，位置可以排版：

- 先选「归属页面」，再**一次多选**图片上传；同一页内按文件名排序，建议命名成 `01-xxx.jpg`、`02-xxx.jpg`
- 到「外观 → 页面排版」选这一页，点「补齐照片槽位」：活动回忆①/②各补 2 个、同行伙伴补 1 个；也可以「添加成员照片」自己加槽位
- 默认顺序：活动回忆为「名称 → 日期 → 承担工作（居中）→ 两张照片」；同行伙伴为「人数 → 伙伴文案 → 一张照片」
- 照片槽位和文字、装饰图一样可以拖动、缩放；右侧可改照片序号（第 1/2 张）、填充方式、高度和圆角
- 保存主题后所有使用该主题的成员按同一位置显示自己的照片
- 如果这一页的排版里还没有照片槽位，成员端会先在页面底部自动兜底显示，避免上传后看不见
- 列表里可以逐张删除；图片文件删除后**不可撤销**
- 支持 jpg / jpeg / png / webp，单张上限 5MB；同名文件默认拦下，可勾选「同名覆盖」

### 2.10 批量上传（按文件名自动归属）

在媒体页底部，可以**一次选多个文件**或**整个文件夹**。上传前会先列出每份文件的归属清单，确认后再传。

| 文件名 / 目录结构 | 会给谁 | 落到哪 |
|---|---|---|
| `01-cover.jpg` | 所有成员（共享图） | `images/01-cover.jpg` |
| `2021001-01-cover.jpg` 或 `2021001_01-cover.jpg` | 只有 2021001 | `images/2021001/01-cover.jpg` |
| 文件夹里的 `2021001/01-cover.jpg` | 只有 2021001 | 同上 |
| `2021001.mp3` | 2021001 的背景音乐 | `music/2021001.mp3` |

- 槽位名就是「页面」页签里每个页面的 key（如 `01-cover`、`04-memory-1`、`06-partners`）；页面增删后以媒体页显示的槽位为准
- 旧版槽位名（`01-opening` 等）仍能识别并落到同名文件，报告会按旧名自动回退，但建议改成新名

- 文件名无法识别、学号不在成员表里、超过大小上限的，会在清单里**标红拦下**
- 同名文件默认跳过并说明；勾选「同名文件直接覆盖」再传一次即可
- 整个过程**不改成员数据**，只是把文件放到正确位置

### 2.11 提示、确认与撤销（交互约定）

- **成功/信息** → 屏幕下方（电脑上右下角）的**轻提示**，4.5 秒自动消失，不打断你
- **错误/参数校验** → 必须点确认的**对话框**（这类信息需要你看清）
- **危险操作**（删除成员、批量删除、删除文件…）→ 红色确认按钮，标题写明要做什么
- **带撤销的提示**停留 **10 秒**，上面有「撤销」按钮；提示**本身不响应点击**（防误触），要关只能点右侧的小叉
- **能撤销的**：删除成员、批量删除、批量修改字段、批量重置密码、批量媒体指派、单条编辑保存 —— **撤销会把原密码一起还原**
- **不能撤销的**：媒体文件的删除（图片/音乐文件没留底，确认框里已注明）

### 2.12 外观与主题（配色、字体、边缘动效）

「外观」页签管理报告的主题。主题是**全站共享的配置**：改一个主题，所有使用它的成员立刻生效。

**主题列表**（顶部）：下拉选择要编辑的主题；「新建」「复制」「设为默认」「删除」。

- **默认主题**不能删除；**仍被成员使用**的主题也不能删除（会提示还有几人，先去成员页给他们换主题）
- 没有单独指定主题的成员，统一使用默认主题

**编辑器**（左侧）：

| 字段 | 作用 |
|---|---|
| 装饰颜色 | 屏幕两侧音符与光点的颜色 |
| 大数字颜色 | 志愿时长 / 活动次数这些大数字的渐变终点 |
| 背景图压暗颜色 / 程度 | 有背景图的页面上蒙一层半透明色；程度越大文字越清楚、图越暗 |
| 上浮音符 | 屏幕两侧音符的开关 |
| 环境光效 | 上浮光点与切页光圈的开关 |
| 单独调整某一页 | 给某一屏单独换装饰色 / 大数字颜色 / 压暗；留空=沿用全局，点「恢复全局设置」恢复 |

右侧是**草稿预览**：改字段会实时反映，但只有点「保存主题」才会影响成员。

**页面排版**（切到「页面排版」模式）：

- 先选页面；如果这一页还没排版，点「从当前样式生成」会按现有版式生成一套可拖动的文字
- 拖动元素移动位置，右下角小圆点调整宽度（图片/成员照片还能调高度）；右侧可以直接输入 X、Y、宽、高，也可以改文字、单位、字体、字号、字重、颜色、对齐、透明度和层级
- 文字里可以用占位符绑定成员数据：`{{name}}`、`{{reportYear}}`、`{{volunteerHours}}`、`{{activityCount}}`、`{{activities}}`、`{{activity1Name}}`、`{{activity1Date}}`、`{{activity1Work}}`、`{{activity2Name}}`、`{{activity2Date}}`、`{{activity2Work}}`、`{{partnerCount}}`、`{{partnerLine}}`、`{{partnerCaption}}`、`{{keyword}}`、`{{keywordReason}}`、`{{message}}`
- 「添加文字」「添加图片」可以额外放元素；图片会存进公共装饰素材库
- 「添加成员照片」放的是该成员在媒体页上传的附加图片；「补齐照片槽位」会按页面类型补默认数量（活动回忆 2 张、同行伙伴 1 张）
- 排版按 **390×844 设计稿等比缩放**，背景图铺满屏幕；换手机比例时元素相对位置不变
- 结尾页的「修改密码 / 退出登录」固定在底部，不随排版移动
- 保存后对所有使用该主题的成员生效；没有排版的页面继续用默认版式，点「恢复默认排版」可删除这一页的排版

**字体**：

- 预置 5 款免费商用的中文字体：得意黑、霞鹜文楷、思源黑体、站酷快乐体、马善政毛笔楷书
- 标题字体作用于大标题与大数字，正文字体作用于行文案与寄语
- 也可以「上传」自定义字体，只收 **woff2 / woff**，单文件上限 8MB；**建议先做子集化**（全量中文字体可达数 MB，手机加载慢）
- 自定义字体是**全站共享的两个槽位**（标题/正文）：替换或删除会影响所有选择「自定义」的主题；删除不可撤销
- 预置字体只保留约 4200 个常用字，**生僻字会逐字回退到系统字体**，不会乱码

**预览与生效**：

- 「保存并预览」/「保存并打开真实报告」会先保存，再用所选成员的数据在新窗口渲染（需要当前浏览器已登录管理面板）
- 主题配置的修改**立即影响所有使用者**，且**不在撤销范围内**；「批量应用主题」这个分配动作本身可以在 10 秒内撤销

**指定主题**：单个成员直接点行内「主题」；多人则勾选后点批量条「应用主题」。两处都可以选「默认主题」或某个主题，单条编辑弹层里也有「主题」下拉。

> 如果顶部出现「/meta 缺少 theme/font 字段」的横幅，说明后端镜像没更新：在项目目录执行 `docker compose up -d --build` 后刷新本页。

### 2.13 页面注册表（「页面」页签）

- 页面类型固定：封面 / 数字统计 / 活动列表 / 活动回忆 / 同行伙伴 / 年度关键词 / 部长寄语；数量、顺序、启用状态可调
- 列表里可以启用/停用、上移/下移、编辑（标题、类型、数字字段/回忆序号）、删除；「新增页面」可以选择类型
- 页面 **key** 就是背景图槽位名（如 `01-cover`、`04-memory-1`）；新增页面的 key 自动生成，媒体页会多出对应槽位
- 「年度」保存后，封面显示对应年份
- 「登录页前言」：编辑登录页标题下方的那句介绍，支持换行；留空则登录页不显示这句。保存后成员刷新登录页即可看到，不影响已登录的报告页
- 成员端按启用页面和顺序渲染；如果全部停用，会回退默认 8 页
- 删除页面不会删除磁盘上的背景图；新增页面 key 不同，需要重新上传对应照片
- 页面类型可以重复，但数据字段有限（例如活动回忆只有①/②两份数据），建议默认 8 页就够用

## 5. 已知边界与注意事项

1. **「加入天数」不再展示**：入会日期仍作为成员资料保存，但新的 8 页报告不显示加入天数；数据保留，后续想加页面可以再用。
**当前背景图是占位图**（几张纯色测试图），不是真实素材；音乐是 8 秒测试音，都不是最终效果
2. **iOS 自动播放最严**：iPhone 上音乐基本都要手动点一下（这是系统策略，改不了）
3. **媒体文件删除不可撤销**（没留底）；成员数据删除可撤销（10 秒窗口、服务端 15 分钟内有效）
4. **撤销令牌最多保留最近 20 次改动**，重启容器即清空
5. **HTTPS 尚未启用**：现在是 HTTP，浏览器可能提示「不安全」——校内使用先这样，后续会配证书
6. 面板的批量导入、批量操作上限：**一次 500 人 / 5000 行**；成员列表一次返回最多 200 条（搜索可以缩小范围）
7. 这台机器靠校园网直连提供访问，没有公网入口 —— 校内能开，出了校园网就访问不到
8. **反馈请带上**：手机型号 + 浏览器 + 你点了什么 + 看到什么（截图最好）。出问题的时刻、提示原文越具体越好排查
9. **主题配置的修改立即影响所有使用者，且不在撤销范围内**；「批量应用主题」这个分配动作可以在 10 秒内撤销
10. **主题不会写进 Excel**：导入、编辑、文本批量都不会清空成员已分配的主题；导出也不带主题列
11. **预置字体是子集**（约 4200 常用字），生僻字逐字回退系统字体；自定义字体全站共享两个槽位（标题/正文），单文件上限 8MB，删除不可撤销
12. **登录页与修改密码页不套主题**；主题字体首次加载时可能先显示系统字体、随后切换，这是正常的
13. **页面排版按 390×844 设计稿等比缩放**，背景图铺满屏幕；换手机比例时元素相对位置不变，上下/左右可能有少量背景留白。结尾页的「修改密码 / 退出登录」固定在底部，不随排版移动
14. **排版图片只收装饰素材库**（在编辑器里上传，存到 `images/decor/`）；没有排版的页面继续用默认版式；删除某页排版即恢复默认
15. **主题（含排版）的修改即时生效且不可撤销**；「批量应用主题」这次分配动作可以在 10 秒内撤销
16. **页面注册表控制页数和顺序**：默认 8 页；页面类型固定，新增/删除/排序/停用即时影响成员端；删除页面不会删除照片文件
