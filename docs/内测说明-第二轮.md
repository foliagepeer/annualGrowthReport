## 0. 本轮范围

## 1. 报告内容与页面配置

### 1.1 从固定 7 屏改为 8 页动态报告

默认 8 页：

1. 封面
2. 志愿时长
3. 活动足迹
4. 活动回忆①
5. 活动回忆②
6. 同行伙伴
7. 年度关键词
8. 部长寄语

页面不再写死在 HTML 里，而是由「页面注册表」生成；成员端每次登录按当前启用的页面与顺序重建。

### 1.2 页面注册表（管理端「页面」页签）

- 页面类型固定：封面 / 数字统计 / 活动列表 / 活动回忆 / 同行伙伴 / 年度关键词 / 部长寄语
- 可以**新增、删除、上移/下移、启用/停用、改标题**
- 页面 key 就是背景图槽位名（如 `01-cover`、`04-memory-1`），新增页面会自动多出媒体槽位
- 删除页面不会删除磁盘上的照片；重新加回同 key 的页面才会复用
- 全部停用时回退默认 8 页，不会出现空白报告

### 1.3 年度与登录页前言

- 「年度」保存后，封面显示对应年份；也用于排版占位符 `{{reportYear}}`
- 「登录页前言」是登录页标题下方的一句话，支持换行；留空则不显示，成员刷新登录页即可看到

### 1.4 上一轮的 7 屏、密码、旧字段

- 旧的「加入天数」不再展示（入会日期仍保存）
- 旧的「年度伙伴」不再导入/导出/展示；改用「伙伴人数」
- 旧 11 列 Excel/文本仍可导入；缺的新列沿用库里原值

## 2. 外观、字体与页面排版

### 2.1 主题（「外观」页签）

主题现在是全站共享的配置，可新建/复制/设为默认/删除：

- 装饰颜色、大数字渐变色、背景图压暗颜色与程度
- 上浮音符、环境光效（光点 + 切页光圈）开关
- 标题字体 / 正文字体：5 款免费商用预置字体，或上传自定义 woff2/woff
- 「单独调整某一页」：只给某一屏换颜色/压暗，留空沿用全局
- 成员可单独指定主题；也可勾选多人批量应用；被使用中的主题不能删除

**本轮修复**：首次打开「外观」时，主题里已保存的字体不再显示成「系统默认」；右侧效果预览也会同步主题字体，不会再出现「一打开就像被清空」的情况。

### 2.2 字体

- 预置：得意黑、霞鹜文楷、思源黑体、站酷快乐体、马善政毛笔楷书（约 4200 常用字，生僻字回退系统字体）
- 自定义字体全站共享两个槽位（标题/正文），单文件 8MB，只收 woff2/woff
- 字体没加载完时先用系统字体显示，不会卡住报告

### 2.3 页面排版编辑器

- 390×844 设计稿等比缩放，背景铺满；元素可拖动、缩放
- 元素类型：文字、装饰图片、图片槽位（成员附加图片）
- 右侧拆成「元素」「属性」两个页签；选中元素自动切到属性，可返回元素列表
- 属性可直接输入 X/Y/宽/高，改文字、单位、字体、字号、字重、颜色、对齐、透明度、层级
- 支持占位符：`{{name}}`、`{{reportYear}}`、`{{volunteerHours}}`、`{{activityCount}}`、`{{activities}}`、`{{activity1Name}}`…`{{message}}` 等
- 进入排版页默认就显示**当前可编辑样式**；「补齐图片槽位」「恢复默认排版」都在这一页操作
- 保存后对所有使用该主题的成员生效；主题修改即时生效、不可撤销

### 2.4 本轮的排版修复

- 占位符里带数字的字段（如 `activity1Name`）能正常替换；空值有兜底文案
- 大数字单位（小时 / 次活动 / 位）不再丢失
- 默认排版整体居中，切页光圈跟随内容中心；旧默认模板做了一次性迁移，自定义排版不动
- 活动足迹页主体单独居中，底部字幕「每一次都在场」不再参与测量
- 排版里的 `{{activities}}` 恢复为**活动胶囊**，成员端和编辑器预览一致
- 有附加图片的页面不再叠加切页光圈，避免和照片抢视觉

## 3. 管理端数据与批量操作

### 3.1 附加图片（本轮新增能力）

- 按「成员 + 归属页面」上传，一次可多选；按文件名排序
- 支持 jpg/jpeg/png/webp，单张 5MB；同名默认拦下，可勾选「同名覆盖」
- 排版里用「图片槽位」取第 N 张；没有排版的页面先在页面底部兜底显示
- 批量上传支持 `学号__页面key__文件名.jpg`，或文件夹 `学号/页面key/文件名.jpg`
- 成员预览会列出附加图片数量、文件名与页面排版信息

### 3.2 活动记录与活动日期

- 「活动记录」留空时，自动用两条活动回忆的名称生成
- 批量编辑里可以按每位成员自己的回忆名称逐一生成，也可以统一填一个值
- 活动一/二日期支持多个日期，用「、」分隔（报告里原样展示）

### 3.3 批量与效率

- 勾选支持跨搜索保留；可批量编辑字段、批量媒体、导出所选、批量删除
- 批量编辑补齐了活动记录、两次回忆、伙伴人数、关键词等字段
- 批量媒体支持：指派音乐、设置背景图目录、上传同一张专属图、删除某槽位专属图
- 删除/批量编辑有 10 秒撤销；媒体文件删除不可撤销
- 音乐单文件上限 10MB；请求体上限 12MB

### 3.4 成员预览

- 行内「预览」会显示该成员**实际加载**的背景图、附加图片、页面排版与音乐
- 主题显示名称而不是随机 ID

## 4. 登录与会话

### 4.1 成员登录改为「姓名 + 学号」

- 不再有成员密码、改密页面和 `/api/password`
- 姓名与学号必须和名单完全一致；错误统一提示「姓名或学号不正确」
- 成员登录状态保留 7 天
- 导入导出现在是 **19 列无密码**；旧 Excel/文本里的密码列会被忽略（旧 20 列文本需先删密码列）
- 数据库里的 `students.password_hash` 已删除

### 4.2 管理员与成员会话彻底分离

- 管理员用 `report.admin.sid`，成员用 `report.sid`
- 同一浏览器里登录管理面板不会把成员顶下线，退出面板也不影响成员
- 管理员登录 12 小时；连续输错 5 次锁 15 分钟

## 5. 成员端阅读体验（本轮修复/新增）

### 5.1 页面内照片展示动画

- 进入有照片的页面，照片依次从画面中央放大到接近屏宽，**停留 1.5 秒**后缩回原位
- 动画结束后**点照片**可放大到画面中央；再点一次缩回
- 放大时照片置顶，盖住同页文字与其他照片，**不隐藏字幕**
- 整页背景图不参与；手机开「减少动态效果」时跳过

### 5.2 视觉修复

- 移除了会在部分设备上渲染出横向亮带的整页光晕层
- 环境光效收敛到上半屏，底部不再出现浅色覆盖
- 默认排版居中、光圈跟随内容中心；排版文字有逐条入场动画、数字恢复滚动
- 活动足迹主体居中、活动名称显示为胶囊

## 6. 年度归档与覆盖式换数据（本轮新增）

### 6.1 年度归档（「归档」页签）

- 打包当前**名单 + 成员照片（含附加图片）+ 成员音乐**为 `<年份>.zip`
- **不包含**共享背景图、装饰图、字体、主题、页面配置
- 快照可下载、恢复、删除；同一年重复归档需确认覆盖
- 归档包存放在服务器 `./archives`（容器 `/app/archives`），**不在数据库里**，需要单独备份/轮转
- 上限：上传 ≤2GB、解压总量 ≤6GB、单文件 ≤100MB、5 万条目；拒绝路径穿越/符号链接/损坏包

### 6.2 上传归档包并覆盖

1. 上传后先预览「归档里有多少 / 当前有多少」
2. 勾选要覆盖的类别：**名单 / 照片 / 音乐**（可分别选）
3. 可选「同时把年度设为归档年份」「同时保存为正式快照」
4. 确认后先清空选中类别再写入：
   - 恢复名单会**注销所有成员登录**
   - 文件删除与覆盖**不可撤销**
   - 只恢复照片/音乐时，名单不变

### 6.3 覆盖式导入与批量清空

- Excel/文本导入可勾选「**导入前清空现有名单（危险）**」；预览显示将删除多少人；文件有错误行时整体拒绝
- 名单覆盖导入可 10 秒撤销（只还原名单，不恢复登录会话）
- 批量上传可勾选「**上传前清空成员照片 / 音乐**」；先显示将删除的文件数，确认后清空再上传
- 两类清空都**只动成员数据**：共享背景图、装饰图、字体、主题、页面不受影响

## 7. 部署与升级（给负责人）

本轮包含后端代码与依赖变化，需要重建镜像：

```bash
cd /home/debian/annualGrowthReport
docker compose up -d --build
docker compose exec nginx nginx -t && docker compose exec nginx nginx -s reload
```

- 新增依赖 `yazl` / `yauzl`（归档 zip 读写）
- `docker-compose.yml` 新增 `${ARCHIVE_HOST_DIR:-./archives}:/app/archives` 挂载
- nginx 对 `/api/admin/archives` 放宽到 2GB 并关闭请求缓冲；`static/.restore-*`、`.trash-*` 等点路径一律 404
- 数据库：11-11 的改版新增 `themes`/`pages` 表与 `students` 新字段，**启动时自动迁移**；本次归档功能没有新增表。原有名单、主题、页面、照片、音乐保留
- 管理员与成员刷新页面即可；成员旧密码不再使用

## 9. 本轮已知边界

1. 文件删除不可撤销：恢复归档、清空成员照片/音乐都会直接替换文件。
2. 恢复名单会注销所有成员登录；成员需重新用姓名 + 学号登录。
3. 归档包上限 2GB；恢复期间成员端可能短暂看到更新中的文件，建议低峰操作。
4. 归档只含成员数据；共享图、装饰图、字体、主题、页面不在快照里。
5. 数据库备份不含 `./archives`，请单独备份/轮转，或用 `ARCHIVE_HOST_DIR` 换盘。
6. 只接受本系统导出的归档 zip；损坏包、路径穿越、符号链接会被拒绝。
7. 归档目录与上传图片一样由容器 root 写入，宿主机直接覆盖可能 EACCES。
8. 覆盖式导入名单后，旧成员中不在新文件里的人只能靠归档找回，建议**先归档再换数据**。
